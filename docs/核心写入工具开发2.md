# 核心写入工具开发2

## 交付结果

本期将上周仅支持预校验的七个写入工具扩展为完整的人工审批闭环：

```text
写入指令 → DTO/权限/业务规则预校验 → 标准操作预览 → 创建审批与任务
        → pending_approval → Execute / Reject → 执行前快照
        → 原业务 Service → 任务、审批、聊天消息和审计同步更新
```

直接调用写入工具的 `execute` 验证端点仍会返回 `WRITE_CONFIRMATION_REQUIRED`。只有绑定审批单、处于有效期内、归属当前用户和租户且再次通过权限与业务校验的操作，才可进入真实执行。

## 标准化预览

`WritePreviewService` 统一生成创建、编辑、删除和批量删除四种预览。共享契约包含操作类型、实体类型、风险等级、摘要、风险提示、字段明细、编辑前后值和批量数据列表。

用户预览只展示姓名、邮箱、Title/Role、状态，密码永不返回前端。公司预览展示名称、等级、国家、城市、成立年份、年营收和员工数；前端根据营收和员工数继续显示原有盈利效率着色。

## 审批与任务存储

迁移 `007_ai_write_approval.sql` 只修改 AI 自有表，不修改 `users`、`companies` 或 `relationships`：

- `ai_task_record` 新增 `pending_approval` 状态，以及 `operation_type`、`approval_status`、`rollback_snapshots`。
- 新建 `ai_write_approval`，保存工具、风险、预览、审批状态、有效期和执行时间。
- 审批参数使用 AES-256-GCM 加密后存储，避免密码、邮箱或业务参数以明文落库。
- 创建审批后任务进度为10；通过后进入 running/50；执行成功后 completed/100。

审批默认24小时有效，`AI_APPROVAL_TIMEOUT_HOURS` 可在1至168小时范围内配置。服务启动和每分钟定时扫描待处理审批，使用行锁与 `SKIP LOCKED` 防止多个实例重复处理。超时审批更新为 `expired`，任务更新为 `cancelled`，聊天确认卡同步显示已超时，并写入系统审计。

## 确认执行

`POST /ai-agent/write-tools/approvals/{id}/decision` 支持 `approved` 和 `rejected`：

- 先锁定并检查审批归属、状态和有效期，重复执行会被拒绝。
- 通过后重新执行 DTO、权限和业务规则校验，避免预览后数据状态变化导致脏写。
- 编辑和删除完整保存原记录；批量删除保存全部记录；创建保存去敏后的操作参数。
- 七个工具的 `execute()` 只调用 `UserService` 或 `CompanyService`，复用原有创建、编辑、删除和多选删除逻辑。
- 成功、失败、驳回和超时均同步任务、审批、聊天消息与 `ai_operation_audit`。

主要接口：

| 接口 | 用途 |
| --- | --- |
| `POST /ai-agent/write-tools/{name}/request` | 预校验并创建审批任务 |
| `POST /ai-agent/write-tools/command` | 在聊天中解析白名单 `/write` 指令 |
| `GET /ai-agent/write-tools/approvals` | 按状态、操作类型和日期分页筛选 |
| `GET /ai-agent/write-tools/approvals/{id}` | 查看预览、快照、结果和执行日志 |
| `POST /ai-agent/write-tools/approvals/{id}/decision` | Execute 或 Reject |

## 前端交互

- 确认消息支持创建、编辑、删除和批量删除预览，内容可折叠。
- 编辑预览以背景色高亮变更字段，同时展示修改前后值。
- 删除显示高风险提示；批量用户删除重点展示姓名、角色和邮箱。
- 按钮操作后刷新持久化消息状态，展示待确认、已通过、已驳回、已超时、已执行或执行失败。
- Agent Tasks从真实接口加载审批任务，支持审批状态、操作类型、开始/结束日期筛选。
- 任务详情展示预览、执行前快照、审批状态和执行日志，并能打开对应聊天会话。

- 未授权用户被拒绝，待审批阶段不修改业务表，直接执行继续被拦截。
- 七个用户/公司写入工具的执行方法均通过真实业务 Service 验证。
- 创建、编辑、删除和批量预览结构正确，编辑前后值与高亮标志正确。
- 敏感参数密文落库，密码不进入预览。
- 执行前快照、任务进度、审批状态、聊天状态和审计记录保持同步。
- 重复审批、驳回和超时均不会产生额外业务写入。
- 66条 Swagger API 通过 OpenAPI 解析校验。
